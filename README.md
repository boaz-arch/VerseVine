The idea behind the web site is to create a platform where users can come together and build a community that supports each other. 
The website is made up of two main pages: 
  - Bible veres
  - Prayer request

Bible verse:
  A page with a list of topics and an option to add a bible verse to a topic. The user enters the topic name, book, chapter and 
  verse number and the verse is added under the selected topic.

Prayer request:
  A page with a list of prayer request and a option to add a new one. The user can scroll though the list and add the request to there prayers 
  though out the day. The user can also choose to add there own prayer request and it will be visible to all other users. 

The website also contains an explanation of my biblical views and faith.
